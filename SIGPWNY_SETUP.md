# Steps

1. Install `python3.11`

1. In the project root, run the following:
```
python3.11 -m venv ./env
./env/bin/pip install .
./env/bin/pip install lascar
./env/bin/pip install git+"https://github.com/Ledger-Donjon/visplot"
```

2. To run an example, cd into the specific example folder, then just run the python file with the `../../bin/python` executable.
