# Steps

1. In the project root, run the following:
```
python3 -m venv .
./bin/pip install .
./bin/pip install lascar
./bin/pip install git+"https://github.com/Ledger-Donjon/visplot"
```

2. To run an example, do the cd into the specific example folder, then just run the python file with the `../../bin/python` executable.
